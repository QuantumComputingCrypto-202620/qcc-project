# qae-options: Report

**Option pricing with quantum amplitude estimation: QAE, IQAE and MLAE compared with Monte Carlo
on a bimodal distribution and a digital payoff.** Design and definitions: [SPEC.md](SPEC.md).
Every number comes from a committed file in [`results/summary/`](results/summary/), and every
figure in [`results/figures/`](results/figures/) is regenerated by [`run_all.sh`](run_all.sh)
from [`configs/`](configs/).

Units: prices and errors are in price units (S₀ = 100, payout Q = 1 for digitals). One oracle
query is one application of A or A†; the Grover operator costs 2, so a circuit with k Grover
applications costs 2k + 1 per shot. Every quantum circuit gets 100 shots. Errors are medians
over R seeded repetitions, with 16th–84th percentile bands.

## 1. Verifiable claim

Bimodal lognormal mixture, digital call with strike 100, n = 5 qubits, ε = 10⁻³ (E2, E3):

> "To reach a price error ε = 10⁻³, IQAE uses **X ≈ 3,700** oracle queries and Monte Carlo uses
> **Y ≈ 117,000** samples; the QPE-based version uses **Z = 6** more qubits and a transpiled
> depth **W ≈ 38** times larger."

| Field | Value | How |
|---|---|---|
| X (IQAE) | 3,659 queries | E2 median-error curve interpolated at ε, between ε_target = 0.01 (error 1.003 × 10⁻³) and 0.003 |
| Y (MC) | 117,102 samples | Same interpolation on the MC curve |
| Z | 6 qubits | Canonical QAE needs m = 6 evaluation qubits with MLE post-processing (12 vs 6 qubits) |
| W | 38.3 | Composed transpiled depth, 6.76 × 10⁶ for QAE (m = 6) vs 1.76 × 10⁵ for IQAE (largest k = 12) |

Sources: [`e2_convergence_fits.json`](results/summary/e2_convergence_fits.json) and
[`e3_resources_claim.json`](results/summary/e3_resources_claim.json).

**The claim needs two caveats, both measured:**

1. **Quasi-Monte Carlo beats every quantum estimator.** Scrambled Sobol sampling reaches
   ε with about **170 samples**, about 21× fewer than IQAE's queries. For a one-dimensional
   problem with a single discontinuity, QMC converges much faster than 1/√N (fitted slope
   −0.86). No quantum advantage appears even in query count once a good classical method is
   allowed.
2. **On simulated noisy hardware, nothing reaches ε** (E4). With the FakeSherbrooke noise model
   at full strength, or scaled down to 30 % or 10 %, the best quantum estimate has a median
   error of 0.025–0.095. That is 25–95 times ε, and the best schedule is always the shallowest.
   Even at 1 % of the device's noise, no estimator gets below 2.3 × 10⁻³.

## 2. Model

| Item | Choice |
|---|---|
| Validation distribution (E1) | GBM lognormal: S₀ = 100, r = 0.04, σ = 0.2, T = 1 |
| Main distribution (E2–E4) | Bimodal lognormal mixture modelling a binary event: weight 0.4 on a "bad news" mode at 85, 0.6 on a "good news" mode at 115, log-price widths 0.10, r = 0.03, T = 0.5 |
| Grid | 2ⁿ equally spaced points between the 0.1 % and 99.9 % quantiles; pᵢ is the probability mass of the cell around each point |
| Loader | Generic `StatePreparation(√p)`, the same circuit for both distributions |
| Digital payoff | `IntegerComparatorGate` flips the objective qubit, so a = P(S ≥ K) exactly on the grid |
| European call | `LinearAmplitudeFunctionGate` with rescaling factor c |
| Barrier (stretch) | Up-and-out digital with two monitoring dates (t₁ = 0.5, T = 1): pays if S_t₁ < 120 and S_T ≥ 100. Joint loader on 2n qubits, two comparators and a Toffoli |
| Estimators | qiskit-algorithms `AmplitudeEstimation` (both its grid estimate and its MLE), `IterativeAmplitudeEstimation` (α = 0.05) and `MaximumLikelihoodAmplitudeEstimation` with schedule {0, 1, 2, …, 2^M}. All use a seeded shot-based SamplerV2 |
| Classical | Monte Carlo draws N grid indices from {pᵢ}. QMC uses scrambled Sobol points through the inverse CDF of the continuous mixture, so it targets the continuous price |

**Simulation method.** Noiseless circuits are simulated exactly at the level of unitaries. The
matrix of each distinct sub-circuit (loader, comparator, reflections, Q) is built once from its
definition, so Q^k costs one matrix power. Each circuit's exact output distribution is then
sampled with a seeded multinomial, which has the same statistics as running the circuit with
100 shots. Gate-by-gate simulation would need about 10⁷ gates per circuit at k ≈ 1,500
(IQAE at ε_target = 10⁻⁴).

The IQAE and MLAE circuits, and the QPE circuit of canonical QAE, are the library's circuits
with Grover powers and controls expressed as annotated operations. Tests check that they
produce the same output distributions as qiskit-algorithms' own circuits (to 10⁻¹²), and
that the simulator agrees with Aer gate-level simulation (to 10⁻¹⁰). Noisy runs (E4) are
transpiled to the device and simulated gate by gate on Aer.

## 3. Validation (E1)

GBM lognormal, n = 3–5, R = 10. Table: [`e1_validate.csv`](results/summary/e1_validate.csv).
The three error sources are reported separately.

| Error source | Digital | European call, c = 0.25 | European call, c = 0.05 |
|---|---|---|---|
| Discretization (grid − continuous) | −0.056, −0.079, −0.009 at n = 3, 4, 5 | +0.42, −0.12, −0.05 | same as c = 0.25 |
| Payoff approximation (exact amplitude − grid) | 0 | **+0.69** (7 %) | **+0.028** (0.3 %) |
| Estimation, IQAE ε_target = 10⁻⁴ | ≤ 1.2 × 10⁻⁵ | ≤ 1.3 × 10⁻³ | ≤ 1.0 × 10⁻² |
| Estimation, MLAE M = 6 | ≤ 3.3 × 10⁻⁴ | 0.03–0.06 | 0.15–0.26 |
| Estimation, QAE m = 8 (MLE / grid) | 2 × 10⁻⁴ / 6 × 10⁻³ | 0.05–0.10 / 0.15–0.67 | 0.17–0.22 / **5.7–6.3** |

Continuous references: Black-Scholes call 9.925 and digital 0.5187, both matching
`scipy.integrate.quad` to 10⁻⁶ relative. The barrier digital (n = 3 per date, 9 qubits) is
estimated within 1.1 × 10⁻⁴ (IQAE) of its grid value 0.3794; its continuous price is 0.416.

**Every estimator reproduces its exact amplitude.** The interesting trade-off is in the call.
Going from c = 0.25 to c = 0.05 cuts the payoff-approximation error 25× (it scales roughly as
c²), but magnifies every amplitude error 5×. The price is an affine function of a with slope
≈ (S_max − K)/(2c), about 900 for c = 0.05, so canonical QAE's grid error of ~6 × 10⁻³ in a
becomes ~6 in price. This is why the main study uses
the digital payoff: it has no payoff-approximation error, so every measured error is
estimation error. Discretization error at n ≤ 4 (0.05–0.4) also dwarfs ε; n = 5 is the
smallest grid where it is near 1 %.

## 4. Convergence (E2)

R = 50 seeded repetitions for each of 49 settings. [Figure](results/figures/e2_convergence.png),
[stats](results/summary/e2_convergence_stats.csv),
[fits](results/summary/e2_convergence_fits.json).

| Method | Fitted slope ± std | Queries to reach ε = 10⁻³ |
|---|---|---|
| IQAE | **−1.01 ± 0.06** | 3,659 |
| MLAE | −0.92 ± 0.02 | 5,515 |
| QAE, MLE post-processing | −1.00 ± 0.07 | 9,447 |
| QAE, grid estimate | −0.78 ± 0.09 | not reached by m = 8; extrapolates to ≈ 3.9 × 10⁵ |
| Monte Carlo | **−0.522 ± 0.006** | 117,102 |
| Quasi-MC (Sobol) | −0.86 ± 0.09 | **172** |

- **The quantum estimators show the predicted O(1/N) scaling.** IQAE and QAE-MLE are
  consistent with −1, and MLAE is slightly shallower (−0.92 ± 0.02) over this range. Monte
  Carlo is consistent with −½.
- **Canonical QAE's grid estimate deviates from −1, for a known reason.** Its outputs are
  restricted to the 2^m grid values sin²(πy/2^m), so its error stays flat until the grid
  resolves a. It is constant at 0.065 from m = 2 to 4, and is still 4.3 × 10⁻³ at m = 8. The MLE
  post-processing in qiskit-algorithms removes this, which is why both are reported.
- **QMC's error falls in steps.** A digital payoff averaged over N points takes only values
  j/N, so its error is quantized. QMC targets the continuous price, while every other method
  targets the grid price (their difference is the discretization error, −0.009 at n = 5).

## 5. Resources (E3)

Operating point: the first setting whose median error is within 5 % of ε. Depths are
transpiled on a linear coupling map with basis {rz, sx, x, ecr}, optimization level 2.
Table: [`e3_resources.csv`](results/summary/e3_resources.csv).

| Variant | Operating point | Qubits | Depth | Two-qubit gates |
|---|---|---|---|---|
| A operator alone | — | 6 | 6,980 | 2,114 |
| IQAE | ε_target = 0.01, largest k = 12 | 6 | 176,252 | 54,986 |
| MLAE | M = 4, largest k = 16 | 6 | 232,676 | 72,610 |
| QAE, MLE post-processing | m = 6 | 12 | 6,755,934 | 1,797,728 |
| QAE, grid estimate | not reached by m = 8 | — | — | — |
| Barrier A (stretch) | k = 0 / k = 1 | 9 | 681 / 3,883 | 254 / 1,582 |

Grover powers are too deep to transpile whole, so these costs are composed from transpiled
components: depth(Q^k A) = depth(A) + k·depth(Q), and canonical QAE adds Σⱼ 2^j·depth(cQ) plus
the inverse QFT. Direct transpilation at k = 1, 2, 4 agrees within 2.2 %
([`e3_resources_composition_check.csv`](results/summary/e3_resources_composition_check.csv)).
The composition ignores parallelism between blocks, so composed depths are upper bounds.

QPE costs 6 extra qubits and 38× the depth of IQAE for the same accuracy. Even the cheapest
useful circuit (IQAE, k = 12) has about 55,000 two-qubit gates on a line; at ~10⁻³ error per
two-qubit gate that is orders of magnitude beyond today's hardware. The comparator dominates
this cost (see E5).

## 6. Noise frontier (E4)

n = 3 (4 qubits; one Grover iteration is 344 two-qubit gates on the device) on the
FakeSherbrooke noise model, with gate, readout and T1/T2 errors scaled by 0.01–1. R = 20.
Figures: [error vs queries](results/figures/e4_noise.png) and
[signal error vs k](results/figures/e4_noise_contrast.png).
Frontier: [`e4_noise_frontier.json`](results/summary/e4_noise_frontier.json).

| Noise scale | Best MLAE schedule | Largest useful power k* | Device depth / 2q gates at k* | Best median error |
|---|---|---|---|---|
| 0 (noiseless) | M = 5 | 32 (still improving) | — | 2.9 × 10⁻⁴ |
| 0.01 | M = 5 (M = 2 almost as good) | 32 | 29,275 / 7,908 | 2.6 × 10⁻³ |
| 0.03 | M = 2 | **4** | 3,979 / 1,076 | 2.3 × 10⁻³ |
| 0.1 | M = 0 | **1** | 1,268 / 344 | 2.5 × 10⁻² |
| 0.3 | M = 0 | 1 | 1,268 / 344 | 5.7 × 10⁻² |
| 1.0 (device) | M = 0 | 1 | 1,268 / 344 | 9.5 × 10⁻² |

- **At realistic noise (scale 0.1–1), the frontier is below k = 1.** Adding Grover iterations
  only makes the estimate worse, and every estimator converges toward a fully decohered value
  (error ≈ 0.12). This is the "frontier below k = 1" outcome the spec anticipated.
- **Convergence only appears at ~3 % of today's noise, and only up to k ≈ 4.** Error still
  decreases with queries up to k = 4, about 1,000 two-qubit gates. At 1 % noise the MLAE curve
  is non-monotonic, and it never beats 2.3 × 10⁻³. IQAE under noise behaves the same way.
- The signal-error plot shows why: |P_noisy − P_ideal| for Q^k A grows with depth at every
  scale. It dips only where the ideal probability happens to be near ½, the value a decohered
  circuit gives anyway (for example at k = 6 and k = 32).

**Correction during the project.** The first E4 run showed suspiciously similar results at
scales 0.1 and 0.3. The cause was a bug in `qcc_common.backends.scaled_noise_model`: T1/T2 were
edited in place on objects that do not persist, so thermal relaxation stayed at full strength
for every scale. It now assigns new `QubitProperties`, a regression test checks that both gate
errors and T1/T2 scale, and the numbers above are from the corrected run. vqe-lih's E7 used
scale 1.0, which never touched that code path.

## 7. Cost of loading (E5)

Generic `StatePreparation` loader vs n = 3–7. [Figure](results/figures/e5_loading.png),
[table](results/summary/e5_loading.csv).

| n | Loader 2q gates | A operator 2q gates (bimodal) | Loader share of A |
|---|---|---|---|
| 3 | 5 | 85 | 6 % |
| 5 | 48 | 2,114 | 2.3 % |
| 7 | 253 | 21,793 | 1.2 % |

- Loader cost grows as ~2ⁿ, as expected for generic state preparation, and is the same for both
  distributions. The bimodal shape costs nothing extra with this loader.
- **The loader is not the bottleneck here; the comparator is.** Qiskit synthesizes
  `IntegerComparatorGate` without ancillas, into multi-controlled gates whose cost grows faster
  than the loader's: 98 % of A's two-qubit gates at n = 5. A comparator with ancilla qubits
  would change this balance. Even so, the loader alone costs O(2ⁿ) per A and A†, so loading
  stays a threat to any quadratic speedup as n grows: 2ⁿ grid points need 2ⁿ gates every
  Grover iteration.

## 8. Not done, and limitations

- **E6 (real hardware):** not run, because no IBM Quantum access was available. E4 is the
  substitute.
- **E4 uses n = 3, not the n = 5 of E2,** so that gate-level noisy simulation of deep Grover
  powers stays feasible. With n = 5, one Grover iteration is about 4,400 two-qubit gates on a
  line (E3), so the frontier would be lower still.
- **QAE resources are composed, not transpiled whole.** The composition is checked against
  direct transpiles at small k, and is an upper bound on depth.
- The QMC comparison targets the continuous price, while all other methods target the grid
  price.
- R = 50 (E2), 20 (E4) and 10 (E1). All runs use 100 shots per circuit; IQAE and MLAE results
  depend on that choice.
